# Accurate model pending

The previous procedural car did not accurately represent the user's i20 and has been removed from the application. Version 0.2 uses an attributed actual 2018 Hyundai i20 reference photograph; see ../ATTRIBUTION.md. It is explicitly labelled as a photo, not a 3D vehicle.

A future rotatable asset must match the exact GB body/facelift, have a compatible redistribution licence and separate door geometry. Physical door-state synchronisation also requires a verified vehicle-data source; the stereo Bluetooth audio connection does not supply it. No unverified mesh, remote-unlock action, or fabricated door state is presented as working.
